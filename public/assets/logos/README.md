# Logos del marco

Coloca aqui los logos reales con estos nombres exactos:

- `sopla-white.png`
- `ccbites.png`
- `la-favorita.png`
- `claro.png`

Recomendaciones:

- Usa PNG con fondo transparente.
- Mantiene buena definicion horizontal.
- El logo de SOPLA debe ser blanco, listo para el encabezado celeste.

Cuando estos archivos existan, el compositor Canvas los usara automaticamente en la foto final.
